# Open Source Success

Consciousness succeeds as an open-source project when it is easy to run, inspect, constrain, and extend.

## Installation

- One-command local startup through Docker Compose.
- Manual Python and Vite startup for contributors.
- Works without paid model keys in preview mode.
- Optional only-memories integration is clearly documented.

## Trust

- Every run is stored durably.
- Every procedure mutation is diffable and reversible.
- The smart auditor cannot silently erase its own failure evidence.
- Budgets are visible and enforced.
- Context windows and context usage are visible per run.

## Extensibility

- Providers are adapters, not hardcoded branches.
- Tools and skills are registry entries with capability boundaries.
- States are data first and code second.
- UI can visualize arbitrary strongly connected procedures.

## Operator Experience

- The current state is visible at a glance.
- The graph explains why the next state follows.
- Agent final thoughts are visible next to changed resources.
- Auditor recaps explain model upgrades, downgrades, and procedure edits.
- only-memories writes are linked back to the runs that produced them.

## Contributor Experience

- Typed contracts for states, transitions, runs, models, and recaps.
- Tests for graph integrity, model selection, and restart behavior.
- Small, readable modules.
- Clear docs that explain what belongs in this repo and what belongs in only-memories.
